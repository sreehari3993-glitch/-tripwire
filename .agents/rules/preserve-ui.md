# Rule: Preserve Existing UI and Animations

## Mandatory Directive
**DO NOT IMPROVE, ALTER, OR REDESIGN THE UI, STYLING, OR ANIMATIONS IN THIS PROJECT.**

The user interface and animations must remain exactly as they currently are.

### Specific Constraints:
1. **No UI Overhauls**: Do not modify CSS, color schemes, themes, layouts, typography, or visual component structures.
2. **No Animation Changes**: Do not add, modify, or enhance animations, transitions, micro-interactions, or visual flourishes.
3. **Preserve Current Look & Feel**: The UI must stand as it is now.
4. **Focus Exclusively on Functionality**: When implementing features, bug fixes, or integrations, only touch backend APIs, database models, calculations, data handlers, and purely functional React state/API bindings. Do not alter the visual styling or existing presentation during integration.
